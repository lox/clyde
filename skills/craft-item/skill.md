Craft an item using available ingredients without recursive gathering. args.item is a registry item name; args.count is a positive integer target total inventory count, not a craft count. A crafting table must be reachable within 32 blocks if required. Runtime bindings: bot, mc, goals, goto, sleep, signal. Uses generic recipe discovery and bot.craft for hand recipes. Table recipes use bot.openBlock and public window clicks, waiting boundedly for server-provided output before taking it; recipe output is never fabricated locally. Crafts once at a time, stows cursor items only into known empty inventory slots, and verifies complete inventory progress with an empty cursor. Table crafting additionally verifies retained progress after closing the window. Opened windows are closed even on errors or cancellation without masking the original error. Returns item, final count, and crafts performed. Throws on invalid inputs, missing ingredients/table, full inventory, unsupported recipes, failed progress, navigation/crafting failure, or cancellation. Does not gather prerequisites. Stage revisions separately, preserve failed gate evidence, and promote only explicitly after an independent gate passes.
