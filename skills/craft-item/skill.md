Craft an item using available ingredients without recursive gathering. args.item is a registry item name; args.count is a positive integer target total inventory count, not a craft count. A crafting table must be reachable within 32 blocks if required. Runtime bindings: bot, mc, goals, goto, sleep, signal. Crafts once at a time, stows cursor output only into known empty inventory slots, and boundedly verifies complete inventory progress. Returns item, final count, and crafts performed. Throws on invalid inputs, missing ingredients/table, full inventory, failed progress, navigation/crafting failure, or cancellation. Success leaves the cursor empty.
