Restore hunger using safe ordinary inventory food, including mushroom_stew. args.targetFood is an optional integer from 0 to 20, default 20. Runtime bindings: bot, mc, sleep, signal. Excludes poisonous potato, rotten flesh, spider eye, pufferfish, raw chicken, chorus fruit, and suspicious stew. Uses equip and consume only, waiting boundedly for hunger progress after each consumption. Returns food, targetFood, and consumed food names. Throws on invalid inputs, unavailable safe food while target is unmet, failed hunger progress, consumption failure, or cancellation.
