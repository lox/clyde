Craft and place a crafting table at args.at, an integer {x,y,z} identifying air above a solid floor. Requires an inventory table, compatible planks, or enough craftable logs/wood/stems; performs no gathering. Runtime bindings: bot, mc, Vec3, goals, goto, sleep, signal. Supports registry plank types, including birch planks from a birch log. Boundedly synchronizes blocks and verifies actual inventory output after each plank or table craft, safely stowing cursor stacks into known empty inventory slots. Verifies placement after a bounded block-update wait. Returns block and at. Throws on invalid location, insufficient materials, full inventory, failed progress, navigation/placement failure, or cancellation. Success leaves the cursor empty.
