Collect logs or stems using the collectBlock plugin for breaking and drop collection. args.count is a positive integer target total inventory count; args.block defaults to oak_log. Runtime bindings: bot, mc, sleep, signal. Searches numeric block types within 32 blocks of the starting position and queues the needed block count in one collection call with ignoreNoPath. Boundedly waits for actual inventory updates, then rediscovers remaining blocks if more are needed. Cancellation clears plugin targets, cancels its task, and stops digging. Returns item, actual inventory count, and broken (queued blocks confirmed removed). Throws on invalid input, insufficient accessible logs, collection failure, no inventory progress, or cancellation.
