Deposit items into a supported container. args.item is a registry item name, args.count is a positive amount to deposit, and args.container is an integer {x,y,z} location. Requires enough inventory items and container space. Runtime bindings: bot, mc, Vec3, goals, goto, sleep, signal. Deposits exactly once, always closes the opened window in finally, then waits boundedly for inventory synchronization. Returns item, deposited, and remaining. Throws on invalid inputs, missing items/container, transfer failure, navigation/window failure, or cancellation.
